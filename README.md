# Juego 🎮

Un juego hecho en **Godot 4** por poyosama y Santiago

## Cómo abrirlo

1. Descargá [Godot 4.3+](https://godotengine.org/download) (versión estándar, no hace falta la de .NET).
2. Cloná el repo:
   ```bash
   git clone https://github.com/poyosama/juego.git
   ```
3. Abrí Godot → **Importar** → elegí el archivo `project.godot`.
4. Apretá **F5** para correrlo.

## Estructura

```
scenes/   # Escenas (.tscn)
scripts/  # Código GDScript (.gd)
assets/   # Sprites, sonidos, fuentes (cuando haya)
```
